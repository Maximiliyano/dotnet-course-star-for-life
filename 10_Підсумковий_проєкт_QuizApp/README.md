# Урок 10. Підсумковий проєкт: QuizApp (текстова вікторина)

**Тривалість:** 90 хв
**Тема:** Підсумковий проєкт. Інтеграція усіх знань курсу.

## Цілі

- Зібрати власний проєкт-вікторину з нуля.
- Застосувати **класи**, **колекції**, **цикли**, **методи**, **умови**.
- Захистити проєкт перед класом.
- Отримати фінальну оцінку.

## План (90 хв)

| Час | Дія |
|-----|-----|
| 0–10 | Огляд вимог до проєкту, демо готового QuizApp |
| 10–70 | Самостійна робота над проєктом |
| 70–90 | Захист 3–5 учнів (по 4 хв на проєкт) |

## Вимоги до проєкту

1. **Клас `Question`** — має питання і 4 варіанти відповіді, індекс правильної.
2. **Клас `Quiz`** — містить `List<Question>`, методи `Start()`, `AddQuestion()`, статистику.
3. **Меню**:
   - Почати тест
   - Подивитись питання
   - Додати своє питання
   - Вихід
4. **Принаймні 5 питань** початкових.
5. **Після тесту** — % правильних відповідей і оцінка («Відмінно/Добре/Задовільно»).
6. **Українська локалізація** (`Console.OutputEncoding = ...`).

## Бонусні фічі

- Зберігання питань у файл (`File.WriteAllLines`).
- Категорії питань (історія, математика, спорт).
- Таймер на відповідь.
- Підрахунок часу проходження.

## Критерії оцінювання

| Критерій | Бали |
|---------|------|
| Працює без помилок | 3 |
| Класи `Question` + `Quiz` | 3 |
| Меню з вибором | 2 |
| Статистика результату | 1 |
| Презентація проєкту | 1 |
| Бонусна функція | +1 |
| **Усього** | **10 + 1** |

## Активності

1. **«Демо QuizApp»** (5 хв) — учитель показує готовий приклад. Учні бачать, до чого прагнути.
2. **«Шторм питань»** (10 хв) — учні швидко виписують 5 питань про шкільні предмети або поп-культуру (їх використають у своєму QuizApp).
3. **«Парне коду-ревʼю»** (10 хв) — за 5 хв до захисту пари обмінюються кодом, дають по 1 поліпшення.
4. **«Гранд-фінал»** — захист проєктів. Учні запускають свої вікторини, інші учні відповідають як гравці.
