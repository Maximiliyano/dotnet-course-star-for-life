# Урок 4. Домашнє завдання

## Завдання: «Помічник з вибору одягу»

Створіть проєкт `HW04_DressAdvisor`. Програма запитує:
1. Температуру на вулиці (`int`, у °C).
2. Чи йде дощ (`true`/`false`).
3. Чи дує вітер (`true`/`false`).

Виведіть рекомендацію щодо одягу:

| Умова | Що порадити |
|-------|------------|
| t > 25 | «Шорти і футболка» |
| 15 ≤ t ≤ 25 | «Джинси та футболка» |
| 5 ≤ t < 15 | «Куртка» |
| -5 ≤ t < 5 | «Тепла куртка» |
| t < -5 | «Зимовий пуховик» |
| Якщо дощ | «+ парасолька» |
| Якщо вітер | «+ шапка» |

## Бонус (★)

Замість окремих рядків об'єднайте поради через `+`:
```
Рекомендуємо: Куртка + парасолька + шапка
```

- Урок 5: програма починає **повторювати** дії — цикли `for`, `while`.
- Зробимо гру «Вгадай число».
