# Урок 4. Розгалуження: if, else, switch

**Тривалість:** 90 хв
**Тема:** Умовний оператор `if/else/else if`, оператор `switch`, тернарний `?:`, логіка ухвалення рішень.

## Цілі

- Будувати програми, які поводяться по-різному залежно від даних.
- Використовувати `if`, `else if`, `else`.
- Використовувати `switch` для кількох варіантів.
- Поєднувати умови з операторами `&&`, `||`, `!`.

## Активності

1. **«Що б ти зробив?»** (3 хв) — учитель ставить ситуації: «Якщо йде дощ — що ти візьмеш?» Учні розповідають у вигляді `if/else`.
2. **«Алгоритм вранці»** (3 хв) — учні описують своє ранкове рутинне «програмування»: `if (час < 7:00) → спати, else → встати`.
3. **«Камінь-Ножиці-Папір» Live coding** — учитель пише гру разом з класом. Учні диктують кожну умову.
