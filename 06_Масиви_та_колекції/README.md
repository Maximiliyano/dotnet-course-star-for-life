# Урок 6. Масиви та колекції (List)

**Тривалість:** 90 хв
**Тема:** Масиви фіксованого розміру, `List<T>`, `foreach`, пошук, сортування.

## Цілі

- Розрізняти масив (`int[]`) і список (`List<int>`).
- Доступ за індексом (з нуля!).
- Обхід через `for` і `foreach`.
- `Add`, `Remove`, `Count`, `Contains`, `Sort`.

## План

| Час | Дія |
|-----|-----|
| 0–5 | Повторення |
| 5–25 | Презентація |
| 25–40 | Демо: «Журнал оцінок» |
| 40–65 | Парна практика |
| 65–80 | Завдання |
| 80–90 | Підсумок |

## Активності

1. **«Парта = масив»** (3 хв) — учитель вказує на парти у класі: парта №0, №1, ... Це масив (індекси з нуля). Учні розуміють, чому з нуля.
2. **«Жвавий список»** (live) — створюємо `List<string>` улюблених фільмів класу: учні називають, учитель додає через `Add`. Сортуємо.

## Складнощі

| Проблема | Рішення |
|---------|--------|
| Індекс з 1 замість 0 | Підкреслити: перший — 0, останній — `Length - 1`. |
| `IndexOutOfRangeException` | Завжди перевіряємо межі або беремо `Length`. |
| Різниця масив vs список | Масив = парта, не пересунути. Список = коробка з предметами, додаємо/прибираємо. |
