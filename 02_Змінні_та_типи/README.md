# Урок 2. Змінні та типи даних

**Тривалість:** 90 хв
**Тема:** Що таке змінна, базові типи даних (`int`, `double`, `string`, `bool`, `char`), інтерполяція рядків, `var`.

## Цілі уроку

- Розуміти, що таке **змінна** і навіщо вона потрібна.
- Вміти оголошувати змінні з різними типами.
- Правильно називати змінні (camelCase).
- Використовувати **інтерполяцію** рядків (`$"..."`).
- Розрізняти `int`, `double`, `string`, `bool`, `char`.

## План уроку (90 хв)

## Ключові поняття

- **Змінна** — іменована «коробка» для значення в пам'яті.
- **Тип даних** — що саме «коробка» вміє зберігати: число, текст, true/false.
- **Літерал** — конкретне значення у коді: `42`, `"Привіт"`, `true`.
- **Ініціалізація** — присвоєння початкового значення.
- **Інтерполяція** — вставка змінних у рядок: `$"Привіт, {name}!"`.

## Активності

1. **«Куди скласти?»** (3 хв) — учитель називає значення (вік, ім'я, ріст, чи любиш морозиво), учні гукають правильний тип (`int`, `string`, `double`, `bool`).
2. **«Імʼя змінної»** (3 хв) — гра: яке з імен правильне? `age`, `2age`, `моя_змінна`, `userAge`, `user-age`. Чому?
3. **«Анкета вчителя»** (live coding) — заповнюємо змінні `name`, `age`, `subject`, `isFunTeacher`, виводимо.

## Складнощі і реакція

| Проблема | Рішення |
|---------|---------|
| Учні плутають `int` і `double` | На прикладі: вік — `int`, зріст у м — `double`. |
| Забувають крапку з комою | Підкреслити при кожній помилці компіляції — IntelliSense її показує. |
| Не розуміють `var` | Показати: `var x = 5;` — компілятор сам знає, що `int`. Але це не «без типу»! |
| Інтерполяція не працює | Перевірити, що є `$` перед лапками. |
