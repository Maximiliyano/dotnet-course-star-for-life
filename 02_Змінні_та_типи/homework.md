# Урок 2. Домашнє завдання

## Завдання: «Картка героя гри»

Створіть новий проєкт `HW02_GameCharacter` і опишіть свого персонажа з гри (Minecraft, Fortnite, Genshin Impact — на ваш смак).

### Вимоги

Створіть **не менше 7 змінних** різних типів:
- `string name` — імʼя героя
- `string heroClass` — клас (воїн / маг / лучник)
- `int level` — рівень
- `int health` — здоров'я
- `double attackPower` — сила атаки
- `bool isAlive` — живий?
- `char rank` — ранг літерою (`S`, `A`, `B`, `C`)

Виведіть «паспорт» героя з інтерполяцією, наприклад:
```
=== ПАСПОРТ ГЕРОЯ ===
Імʼя: Дракон Артур
Клас: Воїн
Рівень: 42
Здоровʼя: 1500 HP
Сила атаки: 87.5
Живий: True
Ранг: S
=====================
```

## Бонус (★)

Додайте дві змінні: `double damageTaken = 200.0;` і обчисліть `health = health - (int)damageTaken;`. Виведіть «після бою»: новий рівень здоров'я. (Зверніть увагу на перетворення `double → int` — цьому навчимось на Уроці 3.)
