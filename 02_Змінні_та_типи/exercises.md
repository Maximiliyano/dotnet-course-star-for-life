# Урок 2. Практичні завдання

## Завдання 1 (★) — «Моя картка»

Створіть 4 змінні (тип на ваш вибір), запишіть свої дані і виведіть їх:
```
Імʼя: Олена
Вік: 16
Зріст: 1.65
Стать (true=Ж): True
```

Підказка: використайте `string`, `int`, `double`, `bool`.

## Завдання 2 (★) — «Інтерполяція»

Зробіть Завдання 1, але **одним** `Console.WriteLine` з інтерполяцією:
```csharp
Console.WriteLine($"Імʼя: {name}, Вік: {age}, Зріст: {height} м");
```

## Завдання 3 (★★) — «Заміни значення»

Створіть змінну `int counter = 0;`. Зробіть `Console.WriteLine(counter);` Потім присвойте `counter = 100;` і знову виведіть. Поясніть у коментарі, що сталося з «коробкою».

## Завдання 4 (★★) — «Площа кімнати»

Створіть 2 змінні: `double length = 4.5;` і `double width = 3.2;`.
Створіть третю — `area`, у яку запишіть `length * width`.
Виведіть: `Площа кімнати: 14.4 кв.м.`

## Завдання 5 (★★★) — «Хто ти?»

Створіть змінні: `name`, `age`, `school`, `favouriteSubject`, `isProgrammer` (bool).
Виведіть «візитну картку» з рамкою:
```
========================
| Привіт! Я Олена.     |
| Мені 16 років.       |
| Школа: Ліцей № 24    |
| Улюблений: фізика    |
| Програміст? True     |
========================
```

## Завдання 6 (★★★ бонус) — «Що таке var»

Спробуйте `var x = 5;` і потім `x = "текст";`. Поясніть у коментарі, чому програма не компілюється.

## Критерії оцінювання

| Виконано | Бали |
|----------|------|
| 1–2 завдання | 3 |
| 3–4 завдання | 4 |
| 5 завдань | 5 |
| 6 завдань (з бонусом) | 6 |
