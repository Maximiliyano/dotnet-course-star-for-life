# Урок 7. Практичні завдання

## Завдання 1 (★) — «Метод Greet»

Напишіть метод `Greet(string name)`, який виводить «Привіт, {name}!». Викличте його 3 рази з різними іменами.

## Завдання 2 (★) — «Метод Square»

Напишіть метод `int Square(int x)`, який повертає `x * x`. Перевірте на 5, 7, 10.

## Завдання 3 (★★) — «Метод Sum»

Напишіть метод `int Sum(int a, int b)`, який повертає `a + b`. Створіть і метод `int Sum(int a, int b, int c)` — це перевантаження.

## Завдання 4 (★★) — «Метод Max3»

Напишіть метод `int Max3(int a, int b, int c)`, який повертає найбільше з трьох.

## Завдання 5 (★★) — «Метод IsPrime»

Напишіть метод `bool IsPrime(int n)`. Виведіть усі прості числа від 2 до 50, використовуючи цей метод.

## Завдання 6 (★★★) — «Метод Factorial»

Напишіть метод `long Factorial(int n)`, що повертає `n!`. Виведіть факторіали 1..10.

## Завдання 7 (★★★) — «Метод ArrayAverage»

Напишіть метод `double Average(int[] arr)`, що повертає середнє арифметичне.

## Завдання 8 (★★★★) — «out-параметри: MinMax»

Напишіть метод `void MinMax(int[] arr, out int min, out int max)`, який знаходить мінімум і максимум одночасно.
