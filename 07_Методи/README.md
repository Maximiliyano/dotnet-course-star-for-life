# Урок 7. Методи (функції)

**Тривалість:** 90 хв
**Тема:** Методи, параметри, повернення, перевантаження.

## Цілі

- Розуміти, навіщо потрібні методи.
- Оголошувати методи (`static`).
- Передавати параметри і повертати значення.
- Перевантажувати методи (overloading).
- Знати про `out` і `ref` параметри.

## План

| Час | Дія |
|-----|-----|
| 0–5 | Повторення |
| 5–25 | Презентація |
| 25–40 | Демо: «Математична бібліотека» |
| 40–65 | Парна практика |
| 65–80 | Завдання |
| 80–90 | Підсумок |

## Активності

1. **«Я — машина для бутербродів»** (3 хв) — учитель проголошує: «Виклик: Бутерброд(хліб, сир, ковбаса)». Метод приймає інгредієнти, повертає бутерброд. Учні самі вигадують методи.
2. **«Хто вже писав метод?»** — нагадайте, що `Console.WriteLine` — це теж метод. Усе, що з дужками — метод!

## Складнощі

| Проблема | Рішення |
|---------|--------|
| Метод не повертає (`void`) і `return value` | `void` — не повертає; для повернення — `int`/`string` тощо. |
| Імʼя методу = імʼю змінної | Не можна. Краще `CalculateSum` для методу, `sum` для змінної. |
| Багато повторюваного коду | Урок — це привід познайомити рефакторинг. |
