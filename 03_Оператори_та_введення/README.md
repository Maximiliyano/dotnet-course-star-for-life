# Урок 3. Введення з консолі, оператори, перетворення типів

**Тривалість:** 90 хв
**Тема:** `Console.ReadLine`, `int.Parse`, `Convert`, арифметичні, порівняння, логічні оператори. Клас `Math`.

## Цілі

- Зчитувати ввід користувача через `Console.ReadLine()`.
- Перетворювати рядок у число (`int.Parse`, `double.Parse`).
- Використовувати арифметичні (`+ - * / %`), порівняння (`== != < >`), логічні (`&& || !`) оператори.
- Користуватися `Math.Sqrt`, `Math.Abs`, `Math.Round`.

## Активності

1. **«Перетворюй»** (5 хв) — учитель пише на дошці `"123" + 1`. Що буде? (Рядок «1231», бо `+` для string — конкатенація.) А якщо `int.Parse("123") + 1`? (124).
2. **«Обчисліть ІМТ»** — учні рахують ІМТ на калькуляторі, потім — у програмі.
3. **«Поведінка ділення»** — `5 / 2` дає `2`, а `5.0 / 2` дає `2.5`. Чому?

## Складнощі

| Проблема | Рішення |
|----------|--------|
| `FormatException` при Parse | Уточнити: користувач має ввести лише число. Або `int.TryParse`. |
| `5 / 2 == 2` (а не 2.5) | Цілочислове ділення — обидва оператори int. Зробити `(double)5 / 2`. |
| Кома замість крапки у double | Поясніть про культуру (uk-UA vs en-US). Розв'язок: `double.Parse(s, CultureInfo.InvariantCulture)`. |
