# Урок 3. Домашнє завдання

## Завдання: «Багатофункціональний калькулятор»

Створіть проєкт `HW03_Calculator`. Програма має послідовно:

1. Запитати у користувача 2 числа (`double`).
2. Вивести:
   - суму, різницю, добуток, частку (з округленням до 2 знаків);
   - середнє арифметичне;
   - середнє геометричне (`Math.Sqrt(a * b)`);
   - модуль різниці (`Math.Abs(a - b)`);
   - більше і менше з двох (`Math.Max`, `Math.Min`).
3. Усе у красивій таблиці:
   ```
   ============================
   Сума:                  12.45
   Різниця:                3.21
   Добуток:               45.67
   ...
   ```

## Бонусне (★)

Додайте обробку ділення на 0 (`if (b == 0) ...` або `try/catch`).
