# Урок 8. Домашнє завдання

## Завдання: «Облік улюблених ігор»

Створіть проєкт `HW08_GameLibrary`.

### Клас `Game`

Властивості:
- `string Title`
- `string Genre`
- `int Year`
- `double Rating` (з 10)
- `bool IsCompleted`

Метод `void Print()` — виводить:
```
[Genshin Impact] жанр: RPG, рік: 2020, рейтинг: 9.0/10, пройдена: False
```

Конструктор з 5 параметрів.

### Клас `GameLibrary`

Поле — `List<Game>`. Методи:
- `Add(Game g)`
- `ShowAll()`
- `int CountCompleted()`
- `double AverageRating()`
- `Game? FindHighestRated()`

### `Main`

1. Створіть `GameLibrary`.
2. Додайте 5 своїх улюблених ігор (вигадайте дані).
3. Виведіть усі.
4. Виведіть кількість пройдених і середній рейтинг.
5. Виведіть найкращу за рейтингом.

## Бонус (★)

Додайте метод `SortByRating()` — сортує ігри за спаданням рейтингу.
