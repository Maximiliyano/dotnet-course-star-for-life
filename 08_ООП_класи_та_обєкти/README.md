# Урок 8. ООП: класи та об'єкти

**Тривалість:** 90 хв
**Тема:** Перший власний клас, поля, властивості, конструктори. Об'єкт як примірник класу.

## Цілі

- Розуміти різницю між класом і об'єктом.
- Створювати клас з полями і властивостями.
- Писати конструктор.
- Створювати об'єкти через `new`.
- Знати про модифікатори доступу `public`/`private`.

## План

| Час | Дія |
|-----|-----|
| 0–5 | Повторення |
| 5–25 | Презентація: клас = креслення, об'єкт = виріб |
| 25–40 | Демо: `class Student` + `Library` |
| 40–65 | Парна практика |
| 65–80 | Завдання |
| 80–90 | Підсумок |

## Активності

1. **«Креслення vs виріб»** (3 хв) — учитель показує креслення стола (один) і столи у класі (багато). Аналогія: клас → креслення, об'єкти → столи.
2. **«Хто такий Student?»** — учні описують характеристики (ім'я, вік, клас, оцінки). Це поля!
