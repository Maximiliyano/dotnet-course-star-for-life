# Встановлення IDE Visual Studio Community 2026

> Орієнтовний час: 30–45 хв (залежить від швидкості Інтернету).
> Рекомендовано 16 ГБ, ~20 ГБ вільного місця.

## Крок 1. Завантажити інсталятор

1. Відкрийте посилання: https://visualstudio.microsoft.com/uk/vs/community/
2. Натисніть **«Безкоштовно завантажити»**.
3. Завантажиться файл `VisualStudioSetup.exe` (~5 МБ — це лише завантажувач).

## Крок 2. Запустити інсталятор

1. Двічі клікніть `VisualStudioSetup.exe`.
2. Підтвердіть запит контролю облікових записів (UAC) — натисніть **«Так»**.
3. Дочекайтеся, поки завантажиться основний інсталятор Visual Studio Installer.

## Крок 3. Обрати робоче навантаження (Workload)

У вікні Workloads відмітьте **галочкою** наступне:

- ✅ **.NET desktop development** (обов'язково)
- ✅ **ASP.NET and web development** (опційно — для поглибленого вивчення Web розробки)

## Крок 4. Перевірити окремі компоненти (Individual components)

Перейдіть на вкладку **Individual components** і переконайтеся, що відмічено:

- ✅ **.NET 8 SDK** (Long-Term Support)
- ✅ **.NET Framework 4.7.2 targeting pack** (для сумісності)
- ✅ **C# tools** (зазвичай уже включено)

## Крок 5. Мовний пакет

На вкладці **Language packs** відмітьте:

- ✅ **Українська** (за бажанням)
- ✅ **English** (рекомендовано залишити для перекладу повідомлень про помилки)

## Крок 6. Запустити встановлення

1. Натисніть **Install**.
2. Дочекайтеся завантаження і встановлення (10–30 хв).
3. Після завершення натисніть **Launch** або відкрийте Visual Studio з меню Пуск.

## Крок 7. Перший запуск і вхід

1. Виберіть тему оформлення (рекомендовано **Dark** або **Blue**).
2. Можна **пропустити** вхід через обліковий запис Microsoft (натиснути «Not now, maybe later»). Безкоштовна редакція Community працює без входу 30 днів — далі попросить безкоштовну реєстрацію.

## Перевірка встановлення

1. Відкрийте **Файл → Створити → Проєкт…**
2. У шаблонах оберіть **Console App** (мова — **C#**).
3. Назва проєкту — `HelloTest`, фреймворк — **.NET 8.0** (або новіший).
4. Натисніть **F5**. У консолі має з'явитися `Hello, World!`.

## Поширені проблеми

| Помилка | Як виправити |
|---------|-------------|
| «Microsoft.VisualStudio.Setup.Configuration not found» | Перезавантажити ПК і перезапустити інсталятор. |
| «No SDKs were found» при F5 | Tools → Get Tools and Features → додати **.NET 8 SDK**. |
| Кнопка F5 не запускає проєкт | ПКМ на проєкті → **Set as Startup Project**. |
| Кирилиця у консолі — кракозябри | На початку `Main` додати: `Console.OutputEncoding = System.Text.Encoding.UTF8;` |
