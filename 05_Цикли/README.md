# Урок 5. Цикли: for, while, do-while

**Тривалість:** 90 хв
**Тема:** Цикли як повторення дій. `for`, `while`, `do-while`, `break`, `continue`, `Random`.

## Цілі

- Розуміти, навіщо потрібні цикли.
- Писати цикл `for` з лічильником.
- Писати цикл `while`, коли заздалегідь не відомо, скільки разів.
- Використовувати `break` і `continue`.
- Створювати випадкові числа через `Random`.

## План

| Час | Дія |
|-----|-----|
| 0–5 | Повторення |
| 5–25 | Презентація |
| 25–40 | Демо: «Гра Вгадай число» |
| 40–65 | Парна практика |
| 65–80 | Завдання |
| 80–90 | Підсумок |

## Активності

1. **«Скільки разів плескаєш?»** (3 хв) — учитель командує: «10 раз плескаємо», «поки я не скажу стоп — плескаємо». Перше — `for`, друге — `while`.
2. **«Гра Вгадай число»** (live) — комп'ютер загадує число 1–100, учні вгадують, програма каже «більше» або «менше».

## Складнощі

| Проблема | Рішення |
|---------|--------|
| Безкінечний цикл (`while (true)` без `break`) | Підкреслити: завжди є умова виходу. |
| `i++` vs `i--` | Покажіть зворотній цикл: `for (int i=10; i>=1; i--)`. |
| `break` vs `continue` | `break` — повністю вийти, `continue` — пропустити цей раз. |
