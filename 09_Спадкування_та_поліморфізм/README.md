# Урок 9. Спадкування, поліморфізм, інкапсуляція

**Тривалість:** 90 хв
**Тема:** Базовий клас і нащадок, `:`, `base`, `virtual`/`override`, `abstract`, інкапсуляція через `private`.

## Цілі

- Створювати ієрархію класів через спадкування.
- Перевизначати методи (`virtual` + `override`).
- Розуміти, що таке поліморфізм.
- Користуватися `abstract` класами і методами.
- Знати чотири стовпи ООП: інкапсуляція, спадкування, поліморфізм, абстракція.

## Активності

1. **«Хто я?»** (3 хв) — учитель: «Я ссавець. Я людина. Я вчитель.» Кожен наступний — спадкоємець попереднього. Учні називають свої «ланцюжки спадкування».
2. **«Скажи звук»** (live) — клас `Animal` з методом `Sound()`. Дочірні класи переозначають. Демо поліморфізму.
